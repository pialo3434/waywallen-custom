# Waywallen Custom website

Static project site for the independent Waywallen Custom build. The page introduces the project and its goals for the Linux wallpaper community, then shows the features with actual Waywallen screenshots. The browser color controls demonstrate the adjustments on a NASA photograph.

Preview locally with `python -m http.server 8000`, then open `http://localhost:8000/`. GitHub Pages publishes the `main` branch root. The site uses relative asset URLs.
