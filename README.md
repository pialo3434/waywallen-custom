# Waywallen Custom website

Static project site for the independent Waywallen Custom build. The opening reel uses original wallpaper artwork. The scene comparison, folder gallery, and palette preview demonstrate the changes included in the custom app.

Preview locally with `python -m http.server 8000`, then open `http://localhost:8000/`. GitHub Pages publishes the `main` branch root. Assets use relative URLs.
